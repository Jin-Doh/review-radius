# Security policy

## Supported version

Security fixes target the latest commit on `main`. This project does not yet
publish versioned release branches.

## Report a vulnerability privately

Use [GitHub private vulnerability reporting](https://github.com/Jin-Doh/review-radius/security/advisories/new).
Do not disclose a suspected vulnerability in a public issue, discussion, pull
request, or review comment.

Include, when available:

- the affected skill step, script, workflow, or documentation contract;
- impact and plausible abuse scenario;
- a minimal reproduction without live credentials or private data;
- affected versions or commits;
- suggested mitigation or known workaround.

The maintainer will validate the report, coordinate a bounded fix, and publish
an advisory when warranted. No response or remediation SLA is currently
promised by this single-maintainer project.

## Scope

Examples of in-scope reports include unsafe GitHub write behavior, credential
exposure, permission escalation, untrusted-input execution, or workflow supply-
chain compromise. General feature requests and non-sensitive correctness issues
belong in the public issue tracker.
