# Bibliography

Sources are identified by the stable IDs used in the claim ledger. Registry and
search observations are snapshots from 2026-08-04 and can change.

- `src_github_api` — GitHub, [REST API endpoints for search](https://docs.github.com/en/rest/search/search).
- `src_npm` — npm registry, [review-radius endpoint](https://registry.npmjs.org/review-radius).
- `src_pypi` — Python Package Index, [review-radius JSON endpoint](https://pypi.org/pypi/review-radius/json).
- `src_crates` — crates.io, [review-radius query](https://crates.io/api/v1/crates?q=review-radius).
- `src_rubygems` — RubyGems, [review-radius endpoint](https://rubygems.org/api/v1/gems/review-radius.json).
- `src_verisign_rdap` — Verisign, [reviewradius.com RDAP record](https://rdap.verisign.com/com/v1/domain/reviewradius.com).
- `src_merriam_radius` — Merriam-Webster, [radius](https://www.merriam-webster.com/dictionary/radius).
- `src_cambridge_radius` — Cambridge Dictionary, [radius](https://dictionary.cambridge.org/dictionary/english/radius).
- `src_w3c_tags` — W3C Internationalization, [Choosing a Language Tag](https://www.w3.org/International/questions/qa-choosing-language-tags).

- `src_iana_registry` — IANA, [Language Subtag Registry](https://www.iana.org/assignments/language-subtag-registry/language-subtag-registry).

- `src_uspto_search` — USPTO, [Search our trademark database](https://www.uspto.gov/trademarks/search).
- `src_wipo_branddb` — WIPO, [Global Brand Database](https://branddb.wipo.int/en/quicksearch?by=brandName&v=Review%20Radius).
